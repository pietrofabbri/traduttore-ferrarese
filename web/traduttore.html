Impostazioni di invio (una volta sola, restano in questo browser)

L'invio apre una segnalazione con l'etichetta correzione nel repository, e un workflow la archivia in dati/correzioni/. Serve un token GitHub: chi è proprietario del repository usa un token fine-grained limitato a questo repository con il solo permesso Issues: read and write; un collaboratore usa un token classic con il solo permesso public_repo, perché GitHub non dà i token fine-grained per i repository di un altro account. Il token resta solo in questo browser. Senza token la pagina non chiama nessuno: Copia e Scarica funzionano lo stesso.

Progetto di «I cinque duchi». Nessun account, nessun server, nessuna richiesta di rete: la pagina funziona anche senza connessione. Il livello «modello» non e' in questa pagina: richiede una chiave e gira solo dal terminale.
